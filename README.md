# PyQuest · practicar_python

Web para aprender y practicar Python jugando, pensada para la optativa **Introducción a la programación** de ASIR.

- 14 mundos y 67 retos, desde `print()` hasta clases, generadores y decoradores.
- Mundos marcados como **Entra en clase**: `input()`, `random`, funciones, validación de datos, el proyecto *Piedra, papel, tijera, lagarto, Spock* y proyectos tipo examen.
- El código se ejecuta con Python de verdad en el navegador (Skulpt), con `input()` simulado.
- XP, niveles, rachas, escamas, logros y minijuegos: Contrarreloj, Ordena el código y Simulacro de examen (25 minutos, sin pistas).

## Uso

Es una web estática de un solo archivo: abre `index.html` en el navegador o publícala en cualquier hosting estático (Cloudflare Pages).

El progreso se guarda en el navegador (`localStorage`).
